# Media source and truthful labels

This Astro prototype reuses only the **original generated media for SERA / COAST** already in `apps/developer-project/public`; all binaries are reused using Git's content-addressed blobs, not downloads from outside sites. Source asset names:

- `assets/sera-hero.webp` — generated fictional architectural exterior / background-video poster.
- `assets/sera-pool.webp` — generated fictional terrace and infinity pool / editorial.
- `assets/sera-architecture.webp` — generated fictional warm stone façade / shadow mask study.
- `assets/developer-desert.webp` — generated fictional desert residence / scroll-video poster.
- `assets/residence-a.webp`, `assets/residence-b.webp` — generated sample residence concepts.
- `media/sera-concept-motion.mp4` — original animated still motion of fictional coastal residence / no live footage.
- `media/developer-concept-motion.mp4` — original animated still motion of fictional desert architecture / no live footage.

The overlay leaf shadows are procedural SVG shapes animated by GSAP (not footage). These animations are indicative only and do not imply photorealistic virtual tours, actual construction, certification, or promised dimensions.
