## Decision: rebuild visually, preserve NORTHLINE product

Use the overall *type of visual rhythm and visitor journey* from SERHANT.: bold, image-first hero with immediate search → photographic destinations → large featured opportunity imagery → immersive editorial story → highlighted collections → practical company methodology → conversion funnel → useful follow-up content. **Do not duplicate SERHANT.'s exact layout, proprietary code, logo, slogans, media, brand palette, real properties, staff, awards, metrics or claims.** NORTHLINE remains a distinct fictional brand; adapt visual patterns, not a one-to-one clone.

This replaces the Christie’s-first editorial direction documented in V4.2, while retaining the essential NORTHLINE investor-advisory functionality (rather than transforming it into a brokerage with real MLS listings).

### 03 — More detail on critical elements

**Hero**: exact SERHANT. brand treatment, actual SERHANT. homepage videos, positioning claims, typography details or assets are NOT transferred. Design should have the same *cinematic-to-utility* hierarchy: striking place image and bold name/statement at the top, then immediately useful search controls. At 375 px the headline and **Start investor brief** control must be usable; image doesn't block controls for multiple screens. No fake autoplay button or video unless actual original film is available.

**Regions**: Dubai is urban/high-rise, Lisbon is tile/stone/Atlantic, London is distinctly urban/heritage. These cannot be the same stock image with a different title. Each destination independently updates filters/quiz; image assets must be different across NORTHLINE and the other portfolio websites.

**Example opportunities**: static fictional sample data, not live property offers. Use existing matching data source and prices as illustrative planning envelopes, not real available homes. Filter/rank by budget, market, objective, property stage and timeline. If no match, show a truthful empty state; never invent results to satisfy a search. Avoid unsupported yield/return claims.

**Video**: one optional short original film from the same study properties. If unavailable, a strongly composed still photo is an acceptable final state; do not embed SERHANT.'s video or show an inert Play control.

**Conversion**: no wall of subscription forms, no brand authority stats (followers, sales, press, awards, agents, transactions), no testimonials, no real referral network claims. Preserve NORTHLINE's current utility-led design goals and accessibility.

## 04 — Functionality preservation / acceptance contract

Current NORTHLINE V4.2 functions that MUST survive:
- 7-step qualification flow: budget, objective, market, stage, timeline, financing, optional contact and ability to go Back/Next; state persists.
- Contact **not required** to see example matches.
- Dynamic fictional recommendation matching; examples change by budget/market/stage, objective and timing affect ordering; explicit no-match state.
- Existing shared calculator: Price, Annual Rent, Service Charges, Management Fees, Occupancy → Gross Yield, Estimated Net Yield, Annual Net Income. Preserve the shared calculation functions and no-profit-guarantee wording. Regression fixture: $450k price, $31.5k annual rent, $3.6k charges, $2.4k management, 90% occupancy → 7% gross, 4.97% estimated net, $22,350 net annual income.
- Consent + honeypot + accessible errors + loading/success/failure and secure configurable HTTPS endpoint only. No fake CRM submission state.
- UTM source, medium, campaign, content, term and GCLID persistence; `page_view`, `start_form`, `form_error`, `quiz_complete`, `generate_lead` only on confirmed successful submit, plus relevant `view_property`-equivalent only for actual sample detail interactions.
- SEO: title/description, canonical with GitHub Pages base, OG, sitemap, robots and valid structured data. Demo inventory must not claim actual Product/Offer availability; noindex until publication scope is decided.
- Astro/TypeScript, Cloudflare Pages-compatible static output, GitHub Pages base deployment, accessible semantics and reduced motion. Do not break other four sites.

**Target responsive viewports:** 320, 375, 430, 768, 1024, 1440 px; no horizontal overflow on initial and completed quiz/results views. Lighthouse goals LCP ≤2.5s, INP ≤200ms, CLS ≤0.1, measured not presumed.
