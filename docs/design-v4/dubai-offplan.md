# MARIS / Dubai Off-Plan — Design reference board V4

**Status:** visual proposal for review; live production pages were not replaced in this phase.  
**Business job:** Convert already-interested Google Search visitors into qualified project enquiries, without burying facts.

## Specific live references

**Primary:** [Ellington — Eltiera Views](https://ellingtonproperties.ae/en/property-for-sale/eltiera-views-jumeirah-islands)  
**Supporting:** [ORLA by OMNIYAT](https://orla.omniyat.com/)  
**Supporting:** [Six Senses Residences Dubai Marina](https://www.sixsensesdubaimarina.com/)  

The references were verified for information architecture and recognizable design patterns. Their live desktop/mobile screenshots, exact font family and pixel measurements have **not** been independently captured or authenticated in this review; do not treat proposed tokens as copied source styles.

## Patterns deliberately adapted
- Clearly separated project brand, units, and brochure/enquiry actions
- Immediate summary of price, unit sizes, handover, and payment terms
- A floor-plan-focused secondary view with selectable residence types

## Do not copy
- Real prices, release schedules, or availability
- Rendering assets, logos, brand language and exact hero layout
- Claims of investment returns

## Prior defect → New composition

**Prior:** One shared editorial template; insufficiently useful first screen; floor-plan and gallery did not feel like a real project selection workflow.

**Proposed:** A crisp white/turquoise split composition where concept architecture and qualification facts are equally strong; 40% of desktop page devoted to facts and prominent CTA. Inner page is a floor-plan explorer rather than another hero.

**Distinct design system:** White #FFFFFF; marine #073E56; sky-tint #F1F8FB; signal turquoise #00809C; heavy Arial/Helvetica; rectilinear buttons.

**How this differs from other four websites:** White utility landing / data hierarchy / geometric sans / visible price and handover, vs dark gallery or fashion editorial.
