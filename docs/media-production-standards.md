# Media requirements — five-site portfolio

**Design goal:** Show a complete, visually convincing real-estate website, never a generic template of texts and cards. Photography and, where justified, videos must be original or properly licensed. Do not take competing sites' assets.

| Website | Minimum distinct visuals | Optional / expected video |
| --- | --- | --- |
| Dubai Off-Plan | 1 striking project hero, 3 residence/interior/amenity images, floor plans and location | Original project concept video if available |
| Investor Advisory | 1 architectural hero, Dubai/Lisbon/London images, 3 illustrative investment images | Original cinematic market montage (optional) |
| Luxury Brokerage | 1 hero; different images per sample listing, area and development; property gallery | Working original/licensed video tour on suitable sample property |
| Seller Leads | 1 property hero and 2–3 marketing/process images | Original property marketing showcase (optional) |
| Developer Project | 1 exterior hero, architectural sequence, residences, 2 amenities, masterplan, floor plans | Original cinematic project teaser recommended |

### Technical and legal acceptance

1. Use AVIF/WebP sources with intrinsic dimensions, responsive sizes, art-directed mobile cropping and descriptive truthful alt text.
2. Preload/high-priority only the actual LCP image; lazy-load below-the-fold media.
3. Video uses a poster, real playable source, keyboard-accessible Play/Pause, reduced-motion-safe behavior, captions when speech exists, mobile fallback and no forced audio. Don't simulate video with a broken control.
4. Every demo visual must be explicitly labeled if it represents an invented property; no inferred real availability, returns, endorsements or construction.
5. Track provenance and rights in a media manifest; never hotlink third-party reference photography without rights.
6. Verify the media on published pages at 320, 375, 430, 768, 1024 and 1440px. Check LCP/CLS and failed requests.
